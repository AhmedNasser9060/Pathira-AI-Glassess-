# Pathira – AI Assistant for Visually Impaired People

## 📖 Overview

Pathira is an AI-powered assistant designed to improve the independence of visually impaired users by helping them understand and interact with their surroundings through computer vision and artificial intelligence.

The application combines multiple AI technologies into a single platform, enabling users to recognize objects, read printed text, analyze scenes, and receive intelligent voice assistance in real time.

---

## ✨ Features

* 🎯 Real-time object detection
* 📄 OCR for reading printed and handwritten text
* 🖼️ Scene understanding using Vision AI models
* 🗣️ Voice interaction with speech recognition and text-to-speech
* 🤖 AI-powered conversational assistant
* 📍 Environmental awareness and contextual guidance
* ⚡ Fast and responsive user experience

---

## 🏗️ System Architecture

1. The user captures an image or speaks a request.
2. The backend processes the input.
3. AI models perform object detection, OCR, and scene understanding.
4. The LLM interprets the results and generates a natural-language response.
5. The response is delivered to the user through voice and text.
